# Atomic.Finance

> Atomic.Finance was a non-custodial, Bitcoin-native financial platform (Toronto, founded 2018) building options and hedging products directly on Bitcoin using Discreet Log Contracts (DLCs) — no custody, wrapping, or swapping. The company is reported out of business, but its open-source DLC and Bitcoin tooling remains published on GitHub and npm.

## Company
- Website: https://atomic.finance/ (currently offline)
- GitHub organization: https://github.com/atomicfinance
- Focus: non-custodial Bitcoin options / hedging via Discreet Log Contracts (DLCs)

## Standards implemented
- Discreet Log Contracts (DLC)
- BIP-340 Schnorr signatures + adaptor signatures
- BOLT / Lightning Network wire + Noise (BOLT 8)
- Bitcoin Core JSON-RPC; Esplora block-explorer API
